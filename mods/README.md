# mods

Each folder here is a data-only mod that ships with the build: `mod.json` plus its PNG images. Today these are the Wes (Mage) and Hazel Druid (Ranger) skins. Players import a mod as a `.zip` of the same files, and can switch any mod on or off from title > MODS. The format is in [docs/MODDING.md](../docs/MODDING.md).
